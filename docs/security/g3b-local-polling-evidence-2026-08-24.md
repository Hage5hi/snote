## Failure-path lesson

The first probe attempt returned a generic fail-closed response. The HMAC and
function environment were healthy; the probe had supplied its own
`X-Forwarded-For` header, which the local gateway combined with transport
metadata into an ambiguous chain that the application correctly rejected.
Removing the client-supplied header and allowing the gateway to supply the
transport identity made the full polling probe pass.

This is not evidence that a hosted gateway overwrites untrusted forwarding
headers. That boundary remains mandatory for G3C.

## Teardown evidence

Teardown reset runtime flags before stopping the stack and required exact
Docker project identity and exact filesystem targets. Independent post-teardown
checks found:

- zero matching containers, volumes, and networks;
- no runtime secret cache;
- no disposable workdir or private helper directory;
- no probe or teardown helper scripts;
- no sensitive staging or HMAC environment variables;
- a clean Git worktree after removing the CLI-generated version marker.

The local log-forwarding sidecar was observed restarting while the stack was
live. Capability probes did not depend on that sidecar, so the backend polling
result above remains valid, but this rehearsal does not claim that every local
Supabase service was healthy.

## Not proved by this rehearsal

The following remain open and must not be inferred from the PASS above:

- real Yjs encryption/decryption and locked-note plaintext exclusion;
- browser IndexedDB outbox acknowledgement, reconnect, reopen, and navigation;
- stalled PWA update behavior;
- private Realtime authorization and refresh;
- Cloudflare crawler, cache, and log containment;
- hosted gateway forwarding-header overwrite behavior;
- hosted migration rollback and restore.

## Decision

G3B's local backend polling subset is complete and cleanly torn down. G3 as a
whole and the release remain **NO-GO**. The next permitted phase is a separately
approved G3C hosted-staging run that closes the unproved boundaries above; no
production action is implied.
